# Nix as a language

Nix is a purely functional, Domain-Specific Language mainly used to define how to create derivations (end-results artifacts from a given revision of source code) on Unix-like and POSIX systems (mainly just Linux and MacOS though). 

A lot of what I'm going to mention, especially when it comes to language concepts, will be better and more robustly explained by the [official language documentation](https://nix.dev/manual/nix/2.18/). However, Nix and its ecosystem are unfortunately infamous for their learning curve and gaps in documentation and how to accomplish certain things.
