# StarOS

An operating system for wizards, designed to appeal to fans of retroufuturism, reliability, and doing cool stuff with computers.

StarOS is for you if:

- Already have experience using a more complete DE + distro, but want to take it to the next level
- You've ever wished debugging a runtime error looked as cool as it does in movies
- You've heard of Nix and NixOS, maybe even having tried them, but they've been too daunting up till now
- You want a reliable, unbreakable operating system that looks good and works well out of the box, with the option to customize it to look however you'd like
- You already use Nix but you wanna try something new for a day
- You like what you see and you want to use bits and pieces for your own system

## Inspirations

- The Tron franchise
  - SolarOS and Encom OS 12 from Tron Legacy
- The Halo franchise
  - Forerunner user interfaces from Halo: CE
    - VISR OS from Halo: Infinite
- The 14th Doctor's Sonic Screwdriver
- Classic 3D vector graphics
