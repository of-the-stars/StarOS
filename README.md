# StarOS

StarOS started out as a fully-fledged NixOS setup that I was making out of spite in response to the initial release of [Omarchy](https://en.wikipedia.org/wiki/Omarchy), but then switched over to being more akin to [kickstart-nvim](https://github.com/nvim-lua/kickstart.nvim) with its main purpose to be a jumping-off point to a well-organized and scalable NixOS configuration.

## Inspirations

- The Tron franchise
  - SolarOS and Encom OS 12 from Tron Legacy
- The Halo franchise
  - Forerunner user interfaces from Halo: CE
    - VISR OS from Halo: Infinite
- The 14th Doctor's Sonic Screwdriver
- Classic 3D vector graphics
